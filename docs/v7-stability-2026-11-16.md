# v7：弯道稳定性修复与发布

用户要求修复最新损坏退赛问题，保持 8 kg 燃油，发布 v7 并推送 GitHub。AGX 已通过准入，赛车卡片显示“已发布代码 v7”。提交 ID `9b5aeb7f-8003-4bd2-b666-73cc1a326e0a`，版本 ID `91e18f5d-5c84-4c5e-bf40-1c777f035d61`，包 SHA256 `f5eca2648526772938758cc220de2465e72133e3aa7814721b4d9c3ecc2d760d`，167006 字节。六个运行文件逐项与上传回执匹配，见 [submission-v7.json](../experiments/submission-v7.json)。

## 改动

1. 抓地估计读取合法 `tyres.allocation` 的本站胎方，而非仅看 soft/medium/hard 标签。C1..C5 相对系数为 0.90、0.94、0.97、1.00、1.02；缺少映射时采用胎种保守回退。最低单轮胎温低于 80°C 时，每度减少 0.4%，该温度因子最低 0.8；保留湿度、磨损和高温项。横向速度规划再保留 8% 余量。这些都是公开资料不完整时的控制假设，不是已拟合出的 AGX 轮胎曲线。
2. 反向速度规划在每个路段把转弯占用的横向能力扣除，再计算可用纵向制动力，提前安排减速。执行动作时，油门与制动同时服从当前横向受力后的剩余轮胎力；使用实测 `g_lat` 和偏航遥测，不把前方弯道直接当作已发生的横向受力，避免临近新弯却完全不刹车。迫近碰撞的紧急制动仍优先。
3. 删除航向跨过 0.30/0.65 rad 时突然切到 18/8 m/s 的目标跳变。侧滑、道路相对航向和异常偏航共同生成连续恢复强度；侧滑约 2° 就可开始响应。甩尾时禁止继续加速和电能超越，并按剩余抓地进行恢复制动。
4. 转向过度时逐渐将前轮指向其局部运动方向并抑制多余偏航，保留 ±0.3 rad 和 1.6 rad/s 的机械限制。恢复不使用固定等待时间或持续降速锁存，状态正常后可立即加速。
5. 保留 8 kg 燃油、v6 ERS、进站/双胎种策略及车辆其余设计，没有加入固定直道速度上限。

## 补充取得的真实事故日志

最初公开复盘时未能读取私有记录。随后用户提供已登录窗口，连接该窗口后取得本人完整训练导出，逐原始字节验证 `export_complete`、SHA256、行数和席位计数。17724 次决策，原记录零 faults；与 v5 commit `438b54e3d0a397099e05c4fb7b7388ff36ab0a6c` 重放时动作差异为零。

真实遥测进一步显示：事故弯进入阶段，7:44.333 已出现前轴滑动标志，7:44.833 出现后轴滑动；7:45.600 车已明显侧滑，旧控制仍给出约 10.5% 油门。这为提前识别失稳和抑制恢复期动力提供了直接依据。单个滑动标志本身不触发持续降速，避免旧版曾有的长期慢车问题。

完整按序重放 v7，在第 4 圈约 3640 m 的历史状态下，过弯计划约 107.1 km/h，历史实际速度约 128.3 km/h；这是针对该状态的计划，**不是固定限速，也不是新的实测速度**。恢复逻辑在 7:45.333（侧滑约 -2.20°、车头偏差约 1.18°）开始介入，早于旧的严重航向保护。7:43.5–7:47.3 窗口中原动作最大刹车 100%，v7 最大约 34.8%；在已耗尽估计横向抓地的历史状态上，v7 会滑行并反打，不再叠加满刹。历史轨迹不随候选动作改变，不能据此宣称已救回车辆。
