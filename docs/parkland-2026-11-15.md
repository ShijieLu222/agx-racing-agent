## 实际上传 v4 中的限制

GitHub main 原来停在 v2（`a92216a`），固定上限 58 m/s、燃油 60 kg；AGX 当前实际上传 v4 的燃油为 22 kg。已从本人账号下载核对，v4 包 SHA256 为 `f07c315296ebdca2a0c392ec2e2a5477f3bff0544d8379df81fd1ae6ea14e378`。不能用仓库 v2 参数解释本场 v4。

实际 v4 的限制包括：

1. `DRY_SPEED_CAP = 300.0 / 3.6`。已知赛道再减 `6 * wetness` m/s，满湿地相当于 **278.4 km/h**。这是自己代码的目标上限。
2. 固定横向预算从 11 m/s² 开始，满湿地乘 0.45，无磨耗已降到 **4.95 m/s²**，没有将自身下压力计入过弯能力。
3. 滑移反馈持续压低抓地估计；后轮滑移逐次压低牵引预算，最低到 **0.35 m/s² 的轮端力/质量预算**，消除滑移后恢复较慢。与油门 0.28 上限叠加，可能使动力长期恢复不起来。没有完整本人决策状态历史，不能精确分摊本场每项损失。
4. 出弯目标每秒最多增加 5 m/s，正向加速度另限 6 m/s²，前方空了也不能立即请求可用全动力。
5. 动力单元温度超过 125°C 时目标压到 32 m/s，并限油门 0.65；节油还会把目标压到 38 m/s。固定阈值与是否实际缺油是两回事。
6. 助推常规只选模式 2，并受固定电量储备、直道判定和恢复等待影响。完整正赛事件中本人没有切到过模式 3 attack。

公开排位片段里本人最高约 301 km/h，与上限及短暂超调相符；冠军约 342 km/h。它们是对应片段观测，不是 v5 极速承诺。排位按顺序进行，途中转雨，本人与冠军早先排位也不能当作同天气实验。

## v5 修改与验证

取消固定最高速度、温度固定限速、正向加速度上限、固定油门压制、滑移驱动的持续降速与目标恢复斜坡。出弯和直道加速可请求 attack，取消固定电池储备和恢复等待。

保留 v4 完整约 2 米地图，检查每个原始节点，避免移动采样漏掉窄峰。结合当前下压力、质量和曲率估计过弯能力，逐区间反向传播制动约束，并主动跟随下降的制动计划。发动机力估计变化不作为直道制动原因。使用简化模型中更稳定的当前曲率转向反馈。

跟车距离依相对速度及制动距离计算；燃油仅在实测耗油推算不足时按缺口比例调整。仍遵守动作取值、机械转向速率、X 区域、超越资格和干地双胎种等要求。严重侧滑、偏航、道路边界和临近碰撞仍会响应，不能在所有路况都全油门。

71 项测试通过；30,000 次合成调用无异常或非法动作，见 `experiments/benchmark-v5.json`。三赛道简化模型均走完一圈、未越过公开道路边缘，见 `experiments/kinematic-v5.json`。模型没有真实轮胎、天气动力学和完整引擎，其圈时不能作为 AGX 成绩。v5 需正式对局验证，不能保证立即达到 1:50 或跑满四圈。
